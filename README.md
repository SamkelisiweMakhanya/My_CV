# Samkelisiwe Portia Makhanya – Professional Portfolio

## About the Project

This project is a personal professional portfolio website for **Samkelisiwe Portia Makhanya**, a Biochemistry and Microbiology Scientist and aspiring Software Engineer.

The website presents my professional background, scientific expertise, work experience, education, professional skills, and current development in software engineering.

The portfolio was created to provide a professional online presence while demonstrating my growing skills in web development and software engineering.

I am a Biochemistry and Microbiology Scientist with over four years of experience across industrial laboratory operations, biotechnology, microbiology, fermentation, pilot-scale bioprocessing and plant tissue culture.

My scientific experience includes:

I am currently expanding my technical skills through a **Software Engineering Short Course through Stellenbosch University in collaboration with HyperionDev**.

My goal is to combine my scientific background with software engineering, programming, data handling and technology.
